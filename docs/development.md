# Development and local use

Requires Node.js 22.12+ and npm.

```sh
npm ci
npm run browser:install
npm run dev
```

Vite serves `http://127.0.0.1:5173`; the local API uses port 8787. Both bind to loopback. Ports are deliberately fixed in development so a conflicting listener produces an actionable error instead of silently changing the API origin. Restart the dev command after changing API code if your platform's watch support differs.

For a production build and CLI:

```sh
npm run build
npm start
# Optional fixed port and no automatic browser opening:
npm start -- --port 8787 --no-open
```

The production CLI selects an available port by default and opens the default browser where supported. Use the URL it prints. Stop with Ctrl+C. Data defaults to `~/.buggd`; set `BUGGD_DATA_DIR` to an absolute directory to change it. Set `BUGGD_PORT` for a default port or `PLAYWRIGHT_BROWSERS_PATH` for an existing Playwright cache. Do not run two processes against the same data directory.

If Chromium is missing, use the in-app installation button or `buggd --install-browser` after installing the tarball. From this repository use `npm run browser:install`. The installer invokes Playwright's supported CLI with visible progress; no browser is silently assumed. Linux can require `npx playwright install-deps chromium` (system package installation may need administrator permission).

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run test:e2e
npm pack --dry-run
npm pack
npm run package:smoke
```

`npm test` includes local servers and real Chromium integration tests. `npm run test:unit` runs only unit tests. The package smoke test installs the generated tarball into an isolated temporary project with runtime dependencies only, starts the installed CLI, runs real fixture scans, checks PDF export, platform/step persistence and linked comparison, and verifies missing-browser guidance. Temporary install data is removed afterward. It may need network access for dependency installation or Chromium setup.

The accessible-name browser bundle is generated by `npm run accessibility:generate` from `src/scanner/evidence/browser-entry.ts`. Build and predev regenerate it automatically. Keep `docs/licenses/dom-accessibility-api.txt` with the bundled output.

Source formatting: `npm run format`. Brand regeneration: `npm run brand:generate`. SVG source geometry and theme usage are described in [brand/README.md](brand/README.md).

This software is intended for macOS, Linux and Windows with supported Playwright dependencies. The current local verification was performed on macOS ARM64 with Node.js 22; the CI matrix targets Linux with Node.js 22 and 24. Do not claim the other environments have passed before CI/manual testing is actually run.

# Public README screenshots

This directory holds **intentionally approved public screenshots** for the Buggd GitHub README. It is separate from ignored, locally retained `docs/screenshots/`, `docs/qa/`, `output/` and runtime scan evidence.

The five screenshots in this README update are actual Buggd v1.1 release-candidate views from an authorised scan of `https://www.wannabyte.co.uk/`, with original user-interface text and recorded values preserved. They have been downscaled to 1600px wide, encoded as WebP and stripped of metadata.

| File | Screen |
| --- | --- |
| `new-scan.webp` | The new-scan landing page |
| `live-progress.webp` | Live scan progress and counts |
| `issues.webp` | Grouped issue overview |
| `guided-fixing.webp` | Guided fixing workflow |
| `highlighted-element.webp` | Highlighted affected link on a captured screenshot |

**Privacy and accuracy:** Before adding further images, review URLs, screenshots, scan identifiers, page contents and user information. Do not commit full saved scan directories or unpublished private site evidence. Some captured website resources were blocked, as Buggd itself warns; those images should not be misrepresented as the way the original website renders for visitors. The footer version shown in these images is the captured release candidate, not a claim about the current release.

Upload screenshots **only** when their publication is approved.

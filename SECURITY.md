# Security policy

Buggd is an inspection tool, not a vulnerability scanner or a complete browser sandbox. Test only websites you own or are authorised to test.

Do not post exploit details, private scan results or secrets in public issues. Use the repository's GitHub private vulnerability reporting feature if it is enabled; otherwise contact the repository owner privately before disclosure. Do not assume a private reporting feature is enabled.

The current release candidate is the supported review target. No response-time or security guarantee is made. See [security architecture and limitations](docs/security.md) before scanning untrusted content.
